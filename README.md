# Amyl 课堂 · Amyl Classroom

咖啡课学员交作业、老师批改的网页应用（PWA）**预览**。

**这是示例数据的演示预览，未接真实付款，也不会上传照片或保存到服务器。** 课程名、价格、学员、作业、评分标准和会员等级名都是示例，仅供打开看流程。

**在线预览：** https://yurryyunyu.github.io/amyl-classroom/

本地打开：

```bash
python3 -m http.server 8767
# 浏览器访问 http://127.0.0.1:8767/
```

打开后先选「学生端」或「老师端」（正式版会按登录账号自动区分，不会让用户自己选老师）。学生可以提交拉花或冲煮作业；老师在批改台打分写评语。

计划中的上线结构（尚未接入）见 [ARCHITECTURE.md](ARCHITECTURE.md)：网站负责介绍，App 负责卖课、物料、交作业和批改。本预览不连接 Shopify 或 Supabase，也没有上架应用商店。
