# Amyl 课堂后端计划

这是一份准备上线的计划，不是已完成的功能说明。当前预览仍是静态 PWA，数据存在浏览器 localStorage，没有登录，也没有真实付款、照片上传或服务器。本文不代表已经建好账号、密钥或店铺。

建议的上线形态与 [ARCHITECTURE.md](../ARCHITECTURE.md) 一致：网站 amylcoffee.com 负责介绍和导流，App 负责买课、买物料、交作业和批改。课与豆子作为同一个店里的两种商品，付款走 Shopify，学习数据走 Supabase。

查阅日期：2026年11月24日（Australia/Sydney）。费用只写当时从官方定价页核对过的数字，并附链接。未核对的项目会写“费用待确认”。

## 1. 登录与身份

用 Supabase Auth。建议第一版用邮箱魔术链接，需要时再加 Apple 或 Google。网站和 App 用同一套登录。

身份不要让用户自己点选“我是老师”。注册默认为学生。老师由 Amy 或管理员在后台开通。建议在 `profiles` 里记录 `role`（student / teacher / admin），必要时用 `teacher_permissions` 限制可批改的课程。

前端按账号进入不同首页：学生看到交作业和学习，老师看到批改台。预览里的“选择入口”只用于演示，上线后应去掉。

权限（RLS）要点：

- 学生只能读写自己的作业，只能看自己的批改。
- 老师只能看被授权课程的提交，并写评语和分数。
- 管理员可改角色和老师授权。

## 2. 作业照片上传

照片存入 Supabase Storage（建议桶名 `homework`），数据库只存路径，不存原图。手机端继续用相机（`capture="environment"`），一次可交多张。

建议在上传前于设备上压缩（预览里已有缩放到最长边约 1200 像素的做法，可沿用并再限制体积，例如单张不超过几 MB）。服务端再校验类型、大小和数量。短视频第一版不做，与现有预览一致。

文件路径按用户和提交编号隔离，并配 Storage 权限：只能上传和读取自己的图；老师可读取被授权课程的图。

## 3. 批改、评分标准和积分

作业暂时只做两种：冲煮（brew）和拉花（latte）。参数放在提交表的 json 字段里，不必为每种作业另建一套表。

建议的核心表（名称可再定，含义应保持）：

- `homework_submissions`：提交人、课程、类型、参数、状态（pending / graded / returned）、提交时间。
- `homework_photos`：提交编号、存储路径、顺序。
- `homework_feedback`：批改人、总分、满分、评分细则 json、评语、可选短提示、批改时间。若启用 AI 初评，另存草稿字段或草稿状态，在 Amy 确认前学生不可见。
- `points_ledger`：积分增减、原因（购买 / 打卡 / 交作业 / 批改 / 优秀 / 调整）、关联类型和编号。积分只通过流水记账，会员等级由积分汇总得出。
- `checkins`：按用户和日期唯一。
- `enrollments`：开通记录，写入 Shopify 订单号。

预览里的示例规则（上线前 Amy 需确认是否沿用）：每日打卡 +5，提交作业 +20，批改 +20，获评优秀再 +30。冲煮评分项为萃取、风味、手法、记录；拉花为对称、对比、奶泡质地、位置与大小、完整度。

## 4. 社区与审核

表建议包括 `posts`、`comments`、`likes`、`reports`。发帖和评论要有状态（已发布 / 待审 / 隐藏）。

必须先定审核规则，建议：

- 新用户前几条先审后发，或全员先发后审并由老师抽查。
- 用户可举报。敏感内容、广告、人身攻击先隐藏，不直接删除，方便申诉。
- 作业分享可以引用提交，但批改分数默认只给提交者看，避免拿分数比较。
- 老师账号显示“老师”徽章。会员徽章来自积分等级。

这些功能现在都还没有后端，预览帖只存在本机。

## 5. Shopify：买课、买物料、付款后开通

课程（数字商品）和物料（实物）都在 Shopify 下单和收款，库存与发货也以 Shopify 为准。App 不自建支付。

付款成功后，用 Shopify webhook（或 Shopify Flow）通知后端，在 Supabase 写入或更新开通记录（`enrollments`）和订单镜像。Webhook 必须校验签名，处理重复通知，失败可重试。开通后再允许学习、交该课作业。

会员折扣可先用 Shopify 折扣码或顾客标签，再与积分等级同步。具体折扣规则由 Amy 决定。

若已有 amylcoffee 的 Shopify 店铺，优先在现有店里加课程商品，不必另开一家店。若没有店铺，需要新建。本文没有创建任何店铺。

## 7. 使用 OpenAI

可以用 OpenAI，但不要让模型直接对学生发布结果。

### 作业照片的 AI 初评

学生提交后，服务端把压缩后的照片和作业参数发给视觉模型，按该作业类型的评分标准草拟各项分数、总评和一句可执行的提示。结果写成“待确认的草稿”，只出现在老师批改台。

Amy（或被授权的老师）必须确认或改写后，学生才能看到。系统不得自动发布初评，也不得在未确认时发通知或加积分。

若模型看不清照片、类型不符或调用失败，应明确标记为“未完成初评”，由老师手工批改，不要编造分数。

### 图像或插画生成

如需为社区配图、课程封面或宣传图生成示例画面，可通过同一套服务端接口调用 OpenAI 的图像生成模型。生成内容要经人工选用后再公开。第一版课堂闭环不依赖这个功能，可放到后面。

### 密钥位置

OpenAI API 密钥只能放在服务端，例如 Supabase Edge Function 的密钥，或同等后端环境变量。浏览器、仓库、GitHub Pages 静态文件里都不得出现密钥。前端只调用已登录用户可访问的后端接口，由后端再请求 OpenAI，并做频率限制和用量记录。

本文没有创建 OpenAI 或其他云账号，也没有写入任何密钥。

## 8. 分阶段上线（先做最小可用）

每一阶段完成后再开下一阶段。不要一开始就做齐社区、AI 和独立支付。

1. **账号与作业闭环。** 建 Supabase 项目，完成登录、角色、作业提交、照片上传和老师手工批改。开通课程可先由 Amy 在后台手动授予，仍不必接付款。用这一阶段验证有人交作业、有人批改。
2. **真实购买与开通。** 在 Shopify 上架真实课程和物料，接好付款和 webhook，付款成功后自动开通课程。App 里可查看订单状态。物料发货仍以 Shopify 为准。
3. **打卡、积分与会员。** 把打卡和积分流水迁到服务器，等级由流水汇总。再视需要同步会员折扣。
4. **社区与审核。** 上线发帖、评论、点赞和举报，并落实先审或抽审规则。
5. **AI 初评。** 在批改台加入 OpenAI 草稿，必须人工确认。稳定后再考虑图像生成等附加用途。
6. **绑定 app.amylcoffee.com。** 把正式域名指到 App，整理官网入口，视需要再考虑应用商店。

## 10. 费用说明（已核对的官方数字）

以下数字来自官方定价页，查阅日期为 2026年11月24日（Australia/Sydney）。实际账单随用量、地区和促销变化，下单前请再打开原页确认。未列出的项目费用待确认。

### Supabase

来源：https://supabase.com/pricing

- Free 计划：每月 0 美元。包含约 50,000 月活用户、每项目 500 MB 数据库、1 GB 文件存储、5 GB 出站流量。免费项目若一周不活跃会被暂停，一个账号最多 2 个活跃免费项目。适合先做第 1 阶段试验，但不适合作为长期生产环境。
- Pro 计划：每月起价 25 美元，含每月 10 美元计算积分（可覆盖 1 台 Micro 实例）。包含约 100,000 月活用户、每项目 8 GB 磁盘、100 GB 文件存储、250 GB 出站流量、每日备份保留 7 天。超出后的加价以定价页为准（例如文件存储超出后约每 GB 0.0213 美元）。付费计划项目不会因不活跃而暂停。一个 Pro 组织若开 2 个 Micro 项目，官方示例为 25 + 10 + 10 - 10 = 每月 35 美元。

Edge Function 调用次数的包含额和超出价，以官方用量说明为准，本文未逐条重核，费用待确认。自定义域名若单独计费，费用待确认。

- Grow：按月付 149 澳元/月，按年付相当于 114 澳元/月。在线标准卡费 1.55% + 0.30 澳元。第三方交易费 1%。
- Advanced：按月付 575 澳元/月，按年付相当于 431 澳元/月。在线标准卡费 1.35% + 0.30 澳元。第三方交易费 0.6%。

### OpenAI API

来源：https://developers.openai.com/api/docs/pricing （价格按每 100 万 token 计，美元，标准短上下文档）

作业初评是按实际输入和输出 token 计费，单次费用随照片多少、提示词长短和所选模型变化，本文不估算“每份作业多少钱”。官方示例模型价包括：

- `gpt-6-luna`：输入 0.10 美元，输出 0.50 美元。
- `gpt-6.1-terra`：输入 1.00 美元，输出 5.00 美元。

选用哪一个，需确认该模型支持图片输入（以官方模型页为准）。建议先用较低价且能看图的型号做试验，再按批改质量决定是否换更贵的型号。

图像生成（例如 `gpt-image-2.6-flare` 或 `gpt-image-2.6-sunburst`）官方标准价为：文本输入每 100 万 token 5.00 美元，图片输入 8.00 美元，图片输出 30.00 美元。单张图的 token 数随尺寸和品质变化，单张成本请用官方图像生成说明里的计算器估算，本文不编造每张单价。

OpenAI 没有固定月费，只有按用量计费（另有账号或额度政策以官网为准）。务必设置用量上限，避免误调用产生高额账单。
